# ADDIF Registry — Public Index

**Status: reserved.** This repository currently has no content.

ADDIF is the Allodial Domain Digital Identification Framework — the identity and records layer of
the AMPAM platform. For the platform overview, see [`ampam-platform`](../../ampam-platform).

## Intended purpose

A public, read-only index: a human-readable pointer to publicly verifiable ADDIF references —
published identifiers and the links by which they can be checked.

The identity stack is five layers deep (LEI, identity token, allodial domain, registry, and proof
layer). Only the outermost, already-public references belong here.

## What this repository must never contain

- the authoritative registry data — that lives in the internal system of record
- database schema, connection strings, or exports
- personal identity documents, certificates, or contact information
- credentials, tokens, wallet keys, or server identifiers

If there is nothing public and safe to publish yet, the correct state for this repository is empty.
An empty index is honest. A filled one that leaks internal data is not.
